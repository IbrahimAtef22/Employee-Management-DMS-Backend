# Employee-Management-System

### Employee Management System to manage all crud operations for employee using Spring Boot for Backend and Thymeleaf for Frontend

### After running the app, you can call these APIs 
- localhost:8080/departments-ui (Add/List Departments)

- localhost:8080/employees-ui  (List of Employees + Add, Update, delete)

- localhost:8080/employees-ui/new (Add a new Employee)

- localhost:8080/employees-ui/edit/{id} (Update an Employee)

### Tools Used:
- Spring Boot 3.5.9
- Thymeleaf
- Java 17
- MySQL
- Lombok 1.18.28
- Mapstruct 1.5.5.Final
